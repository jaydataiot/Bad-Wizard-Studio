# Bad-Wizard-Studio
Where imagination refuses to stay inside the frame.

Bad Wizard Studios is an independent creative studio dedicated to developing immersive worlds through board games, comics, books, digital media, film, podcasts, and interactive web experiences. Every project is designed to tell stories that span multiple forms of media while encouraging creativity, curiosity, and community.

The studio serves as the umbrella organization for three creative divisions:

* 🎲 Bad Wizard Games
* 📚 Bad Wizard Publishing
* 🎙️ Bad Wizard Media

Together they form a connected creative universe centered around original intellectual property, innovative storytelling, and interactive entertainment.

⸻

Philosophy

Bad Wizard Studios believes that stories should not be confined to a single medium.

A board game can become a comic.

A comic can inspire a podcast.

A podcast can become a documentary.

A documentary can inspire a new game.

Each project exists as part of a larger creative ecosystem where every artifact expands the universe.

We strive to create experiences that are:

* Original
* Entertaining
* Educational
* Interactive
* Artistically distinctive
* Community driven

Malgrin

The unofficial mascot of Bad Wizard Studios.

Malgrin the Puce is a small wizard with an enormous personality whose adventures connect nearly every part of the studio.

He appears throughout:

* Games
* Comics
* Podcasts
* Studio announcements
* Promotional videos
* Interactive stories
* Educational content

Although famous for being an exceptionally poor wizard, Malgrin excels at inspiring creativity.
